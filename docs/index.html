为什么用它

把大模型装进你的 QQ 私聊，主打省心、省钱、随时能聊。

彻底无服务器

跑在 Cloudflare Workers 上，不买云主机、不本地常开电脑，零运维零账单焦虑。

QQ 私聊直聊

C2C 单聊机器人，只在你和机器人之间对话，干净私密，不进群。

任意大模型

兼容 OpenAI 协议的 API：DeepSeek、通义、GLM、GPT 随便换，改个变量就行。

签名安全

严格按 QQ 文档实现 Ed25519 签名验证，与官方一致，回调不被伪造。

多轮上下文

对话历史存 KV，保留最近 10 轮、24 小时过期，机器人记得你刚说了啥。

稳定不丢消息

Worker 先秒回 200 再后台跑模型，绕开 QQ 5 秒限制，长回复也不掉。

5 分钟部署

有 Cloudflare 账号加一个 OpenAI 兼容的模型 API 即可。

deploy.sh
# 1. 建 KV 保存对话上下文
npx wrangler kv:namespace create "CHAT_HISTORY"

# 2. 把返回的 id 填进 wrangler.toml 的 kv_namespaces

# 3. 部署
npm install
npm run deploy

# 4. 设置 5 个生产密钥
npx wrangler secret put LLM_BASE_URL
npx wrangler secret put LLM_API_KEY
npx wrangler secret put LLM_MODEL
npx wrangler secret put QQ_APP_ID
npx wrangler secret put QQ_CLIENT_SECRET

# 5. QQ 开放平台 → 机器人 → 接入方式 → Webhook
#    回调地址填：https://<你的worker>.workers.dev/qq-webhook
